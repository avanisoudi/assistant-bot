Configuration

Plateforme : Assistant Bot Pairing

Bot : AssistantBot V1.2.2 fourni par l’administrateur

Exécution : Node.js + Baileys

Stockage session : BOT_AUTH_DIR (à placer sur un disque persistant Render)

Groupes : le bot publie ses groupes réels via bot/panel-bridge.js ; le panneau lit bot/data/groups.json et lui transmet ses commandes. Sans pont installé, l’onglet Groupes affiche l’état réel : aucun groupe lu.

Sans disque persistant, Render peut supprimer la session WhatsApp lors d’un redéploiement ou redémarrage. Le code ne simule pas la connexion : il affiche uniquement un code produit par le processus réel. Aucun groupe n’est inventé non plus : tout vient de WhatsApp ou reste vide.
